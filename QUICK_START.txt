CHESS TACTICS TRAINER — GITHUB PAGES QUICK START

1. Create an empty GitHub repository named chess-tactics-trainer.
2. Clone it with GitHub Desktop.
3. Copy every file and folder from this package into the cloned folder,
   including the hidden .github folder. Commit and push.
4. In GitHub: Settings > Pages > Source > GitHub Actions.
5. In GitHub: Actions > Build and deploy million-puzzle trainer > Run workflow.
   Keep the defaults and run it.
6. Open the Pages address shown by the completed deployment.

The deployed page should display 1,000,522 puzzles: 1,000,000 generated
Lichess puzzles plus the 522 built-in puzzles.

The million puzzles are generated by GitHub Actions as 100 compressed files of
10,000 puzzles each. They are not stored in this ZIP or committed to Git history.
